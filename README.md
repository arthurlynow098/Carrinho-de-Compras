# Carrinho-de-Compras

## Sobre o projeto

Aplicação web Buy Cart em C# e ASP.NET Core. O projeto reúne controladores, modelos, telas Razor, migrações e dependências de Entity Framework e SQL Server.

## Como explorar

Abra `Buy_Cart.sln`. Confira a conexão SQL Server e as migrações antes de iniciar. O projeto declara .NET 8 e pacotes Entity Framework 9; a compatibilidade dessas dependências deve ser revisada antes de considerar a compilação validada.
